# Portfolio Website — MS-0001

## Goal
Build a bilingual (EN/PT) psychologist portfolio + CV site in a single Hugo
repository, with a global practice map and green color palette.

## Approach
- Set up Hugo configuration, base layout, and asset pipeline
- Build data-driven content for EN/PT
- Implement sections: hero, about, approach, global practice/map, CV, contact
- Create inline world map with location markers
- Add CV section with print-friendly styles
- Include Instagram and contact CTAs

## Why This Approach
Hugo provides native i18n, simple data files, and a static setup that is easy to
deploy while keeping content maintainable.

## Risks
- Map visual quality vs. simplicity
- Copy accuracy with limited initial details
- Accessibility contrast for green palette
